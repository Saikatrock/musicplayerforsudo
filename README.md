# For Sudo, with love

A one-page React/Vite love letter with a YouTube playlist soundtrack.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

1. Push this folder to a Git repository.
2. Import the repository at [Vercel](https://vercel.com/new).
3. Vercel automatically detects Vite. Keep the default build command (`npm run build`) and output directory (`dist`).
4. Deploy. No environment variables are required.

The music begins only after the recipient chooses PLAY, respecting browser autoplay rules.
